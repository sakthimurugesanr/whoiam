## ⚙️ Setup Guide (for the animated elements)

This package includes three self-contained animated pieces — no external animation service required for any of them:

| File | What it does |
|---|---|
| `assets/terminal-banner.svg` | Typing-terminal intro animation with a blinking cursor |
| `assets/skill-bars.svg` | Skill bars that fill in on load, with a moving shimmer sweep |
| `.github/workflows/snake.yml` | GitHub Action that turns your contribution graph into a snake animation |

**Steps:**

1. Create (or open) your special profile repo — it must be named **exactly** the same as your GitHub username, e.g. `github.com/YOUR_GITHUB_USERNAME/YOUR_GITHUB_USERNAME`.
2. Copy this entire package into that repo's root — keep the `assets/` and `.github/workflows/` folder structure intact.
3. Find & replace every `YOUR_GITHUB_USERNAME` placeholder in `README.md` with your real GitHub handle.
4. Commit and push to `main`.
5. Go to the **Actions** tab → run **"Generate Snake Animation"** once manually (or wait for the next scheduled run). It will create an `output` branch with your snake SVGs.
6. Refresh your profile page — the terminal banner and skill bars render immediately (they're static assets), and the snake appears once the Action finishes.
